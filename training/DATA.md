# Third-party data

The repository is MIT-licensed (see [LICENSE](../LICENSE)), with one
exception: 100 records in `research_dataset_v3.json`.

Those are the records whose `source` field begins `dolly-15k/`. Each one is an
instruction and its human-written response from
[databricks-dolly-15k](https://huggingface.co/datasets/databricks/databricks-dolly-15k)
by Databricks, Inc. (revision `bdd27f4d94b9c1f951818a7da7fd7aeea5dbff1a`),
which is licensed under the
[Creative Commons Attribution-ShareAlike 3.0 Unported License](https://creativecommons.org/licenses/by-sa/3.0/legalcode).
Those records remain under CC BY-SA 3.0, not MIT, and so does anything derived
from them.

Changes made: `augment_research.py` (`--general`) samples records from the
`open_qa`, `general_qa`, `brainstorming`, `creative_writing` and
`classification` categories, keeping only records with no context passage, a
response of 20 to 600 characters, and nothing about commands or code. It
trims whitespace and rewrites each into a two-turn chat, with the instruction
as the user message and the response as the assistant message. The wording is
otherwise unchanged.

Every other record in this directory's datasets was generated by the scripts
beside it, from tool output: the `--help` text of common command-line tools,
and `cargo clippy` diagnostics on the author's own crates
(`clippy_corpus.json`). Quoted `--help` text remains under its tool's own
license.
